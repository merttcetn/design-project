02Research Question

Can deterministic graph-search + schema-constrained LLMs produce navigation that is provably correct, fluent, landmark-anchored, and accessibility-aware?

Why it's hard
  1. 01Floor plans rarely encode walkable connectivity directly.
  2. 02Free-form LLM output can hallucinate hallways that don't exist.
  3. 03Accessibility constraints must propagate through routing, not just UI.
  4. 04Instructions must read like a human would describe the route.
03State of the Art

Four research families.

Indoor navigation sits at the intersection of four streams. We borrow from each and unify them around natural-language output.

AR + VIO
AR overlays + visual-inertial odometry for inside-out localization. Strong UX, expensive sensors.
Accessibility-Aware Routing
Weighting elevators, ramps, and stair-free paths for wheelchair and limited-mobility users.
Algorithmic Core
Dijkstra, A*, contraction hierarchies on weighted indoor graphs — deterministic and auditable.
LLMs for Spatial Reasoning
Rewriting raw turn lists into natural prose; constrained decoding to keep facts grounded.
OUR GAP
Integrate all four into one system grounded in a real hospital.

06Routing

Dijkstra finds it. The LLM tells it.

Pathfinding
Dijkstra on a small, weighted graph.
weight(edge) = base_cost if avoid_stairs and edge.kind == 'stairs': weight += SOFT_PENALTY
  • Graph is small (≤ 300 nodes); A* heuristic gains nothing.
  • Deterministic — same input, same path. Easy to audit.
  • Accessibility weights compose without re-architecting.
Instruction Rewriting
MiniMax-M2.7 with strict JSON schema.
  1. INraw turn list (e.g. node-43 → edge-118 → node-44)
  2. SCHEMAJSON schema with enum landmarks; no free fields
  3. OUTfluent Turkish, landmark-anchored, accessibility-aware
  4. FALLif schema fails → deterministic templated prose

09Field Study

What people told us.

Informal pilot on-site. Patients, visitors, and one wheelchair user. Small sample, sharp signal.

Liked
  • Step-by-step logic was easy to follow.
  • UI felt intuitive without instructions.
  • Turkish prose felt natural, not translated.
  • Reached destinations on the first try.
Raised
  • Unclear where I'm standing — start point selection felt risky.
  • What if I pick the wrong starting node?
  • Floor change instructions could be more visual.

11What's Next

Beyond one hospital.

The architecture generalizes to any indoor environment with a graph and a story to tell.

Immediate Impact
  • Self-service wayfinding reduces reception load.
  • Accessibility toggle is one switch, not a separate flow.
  • Turkish-first instructions match how patients actually ask.
Next Steps
